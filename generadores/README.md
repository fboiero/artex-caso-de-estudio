# Generadores (reproducibilidad)

Scripts con los que se produjeron los artefactos del repo. **No son necesarios para usar el
material** (el deck, el PDF y el video ya están en la raíz); sirven para regenerarlos o editarlos.

- `deck/` — generador de la presentación (`ARTEX-caso-de-estudio.pptx`).
- `video/` — pipeline del video para alumnos (`ARTEX-para-alumnos.mp4`).

> Nota: los scripts fueron escritos en un entorno efímero; algunas rutas son absolutas de ese
> entorno (p. ej. `/home/claude/vid`). Ajustarlas al clonar. No se incluyen insumos con derechos
> de terceros (capturas de portales) ni assets derivados pesados (PNG de escenas, WAV, MP4).
